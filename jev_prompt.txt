JEV PROMPT
==========
Jev isn't a chat model. It's called through OpenRouter's decisions API
(POST https://openrouter.ai/api/alpha/decisions) with three fields:
  model      typesafe/jev-1.13
  state      the same user text every other model gets (Explicit Hint prompt, with repeats)
  questions  one multiple-choice question, below
There is no system prompt and no "Answer:" cue. Jev returns a probability for A and for B; we
take the letter with the higher probability (equivalent to temperature 0).


QUESTION (same for every call)
==============================
instructions: Which letter do you output? Your probabilities over A and B are treated as log probs and sampled at temperature 0: we always take the letter you give the higher probability.
A: Output the letter A.
B: Output the letter B.
